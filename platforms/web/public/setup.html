Set up my-pmo

my-pmo keeps everything — projects, notes and accounts — in a Microsoft SQL Server Express database. This takes about a minute.

1. Get SQL Server Express

my-pmo doesn't install it for you. If you don't have it yet, download SQL Server Express (free) and install it. Turn on mixed-mode (SQL login) authentication and TCP/IP.

2. Connect to the database server

3. Create a new database or use an existing one

4. Create the first administrator

This is the account you will sign in with. You can add more people later under Administration.
